# User Story (Example — POC Demo Only)

**ID:** US-1042
**Title:** As a customer, I want to reset my password via email so that I can
regain access to my account without contacting support.

**Acceptance Criteria:**
1. User can request a reset link from the login page.
2. Reset link expires after 30 minutes.
3. Reset link can only be used once.
4. User receives a confirmation email after a successful reset.
5. No plaintext password is ever logged or emailed.
